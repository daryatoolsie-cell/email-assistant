👋 Welcome to Email Assistant

This app writes your emails with Claude. To use it, you need your own Claude API key. It's like a password that lets the app use Claude, and you pay Anthropic directly for what you use (about 1¢ per email).

  1. Go to console.anthropic.com and sign up or log in.
  2. Under Billing, add a little credit ($5 lasts a long time).
  3. Open API Keys, click Create Key, and choose Continue with an API key if it asks about identity federation.
  4. Copy the key (it starts with sk-ant-) and paste it below.

Your key is stored only on this Mac, in a file only your account can read. It's sent only to Anthropic.
